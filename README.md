# Inventory Management Dashboard

## Project Overview

An interactive Excel-based inventory management dashboard designed to track and analyze inventory performance across multiple warehouses and suppliers.

The project focuses on providing a structured view of stock levels, reorder requirements, supplier information, and inventory performance using core Excel analytics and visualization features.

## Features

- Track stock levels by item, warehouse, and supplier
- Monitor inventory and reorder status
- Identify low-stock items using conditional formatting
- Analyze stock availability across categories and locations
- Use PivotTables and PivotCharts for interactive analysis
- Filter analysis using Excel slicers and filters
- Clean and structure inventory data for accurate reporting

## Key Analysis Areas

### Inventory Tracking

The dashboard provides visibility into stock levels across different items, warehouses, and suppliers.

### Reorder Monitoring

Inventory items can be monitored based on their reorder requirements to identify products that may require replenishment.

### Warehouse Analysis

Inventory can be analyzed across different warehouse locations to understand stock distribution and availability.

### Supplier Analysis

Supplier-level analysis provides visibility into inventory supplied by different vendors.

### Stock Status

Conditional formatting and dashboard views help identify inventory that requires attention, particularly low-stock items.

## Use Case

This dashboard is designed for small-to-medium businesses and inventory analysts who need a flexible Excel-based solution for monitoring stock performance across suppliers and warehouse locations.

It can support routine inventory reviews and help stakeholders identify products that may require restocking.
